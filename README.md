# MediCenter — Site com Flexbox

Site institucional fictício da clínica **MediCenter**, desenvolvido para praticar **CSS Flexbox**. Conta com menu responsivo com toggle mobile.

## Tecnologias

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## O que foi praticado

- CSS Flexbox como base do layout
- Menu de navegação responsivo com toggle via JavaScript
- Header, seções de conteúdo e rodapé alinhados com Flexbox
